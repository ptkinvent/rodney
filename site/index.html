Rodney

Describe it.
Deploy it.

Rodney builds web apps from a conversation with your favorite AI assistant. Ask for a dashboard, a calculator or a one-pager, and it's published at its own address in seconds. No setup, no hosting, no deploy step.

ptkinvent.com/your-app/

Set it up

  1. Add the MCP server

    The connector lets Claude publish and edit your apps. Copy the address:

    https://mcp.ptkinvent.com/mcp
    1. In Claude, open Customize → Connectors.
    2. Click Add custom connector and paste the address.
    3. Click Add.
    Using Claude Code instead? 
    claude mcp add --transport http rodney https://mcp.ptkinvent.com/mcp

  2. Add the skill

    The skill tells Claude how Rodney works: how to name apps, which files are allowed, and how to update an app later.

    Download rodney.zipor just SKILL.md (for reading, or Claude Code)

    1. In Claude, open Customize → Skills.
    2. Click + Create skill, then Upload a skill, and choose rodney.zip.
    Using Claude Code instead? 
    mkdir -p ~/.claude/skills/rodney
curl -o ~/.claude/skills/rodney/SKILL.md https://ptkinvent.com/SKILL.md

  3. Ask Rodney to build you something

    Start a new chat with the connector turned on, and try something like:

    • Rodney, build me a habit tracker I can use on my phone.
    • Ask Rodney to make a one-page invoice generator.
    • Have Rodney build a dashboard for this week's standup notes.
Apps are public to anyone with the link, so keep secrets out of them. Everything is static HTML: apps remember things in your own browser, not on a server.
